API ini menggunakan prinsip REST. Permintaan dan respons berformat JSON.

## URL dasar

```text
https://api.contoh.com/v1
```

## Format respons

Respons yang berhasil membungkus data di dalam `data`:

```json
{
  "data": [
    { "id": "item_123", "name": "Contoh item" }
  ],
  "has_more": false
}
```

## Kode status

| Kode | Arti |
| --- | --- |
| `200` | Berhasil |
| `400` | Permintaan tidak valid |
| `401` | Kunci API tidak ada atau salah |
| `404` | Sumber daya tidak ditemukan |
| `429` | Terlalu banyak permintaan |
| `500` | Kesalahan server |
